# معجم الكلمات الحقولية المكثفة في القرآن الكريم

**إعداد وابتكار:** فضيلة الشيخ طاهر حسين محمد أدروب الفكي (أبو يحيى)

---

## 🏛️ المنهجية العامة والنواة الصلبة
يقوم المعجم على تجريد الألفاظ القرآنية وتصنيفها ضمن:
* **282 أصلاً حقولياً محورية** (النواة الصلبة).
* **17 مجالاً دلالياً جامعاً**.

---

## 📐 التقسيم الخماسي الفريد للمجاورة والمكملات
1. **الأصل الحقولي الثابت (النواة الصلبة):** المفهوم الجامع الثابت للجذر.
2. **المجاورة الصوتية والصرفية:** بيان أثر الحركة وحروف التعدية والجر.
3. **المجاورة اللفظية (الحقل التكميلي العام):** المكملات المتغيرة بحسب حال المسند إليه والسياق لإبطال الترادف.
4. **الأصل المجاور للحقل (الجسر الدلالي):** الروابط الناقلة للمفاهيم والسلوكيات الإيمانية المجاورة.
5. **التنبيهات المتقاطعة والسياقية:** التمييز الدقيق بين الأبعاد التكليفية والجبليّة بحسب حال المسند إليه.
